# t4h-desafios

> **Resolvendo um desafio?** Estas instruções, as regras e as skills de `.claude/` são para quem mantém o repositório e não valem para quem resolve um desafio. Siga o `AGENTS.md` (ou o `README.md`) da pasta do projeto.

Repositório **público** com os desafios técnicos usados nos processos seletivos e nas vagas da Tech for Humans. Cada processo seletivo é um **projeto**: uma pasta na raiz com seu próprio `README.md`, e dentro dela uma subpasta por área ou desafio. O `README.md` da raiz é só um índice dos projetos.

## Rules

As regras do repositório estão em `.claude/rules/` e valem para qualquer mudança:

- [estrutura-e-nomes.md](.claude/rules/estrutura-e-nomes.md): layout de pastas, nomes e READMEs obrigatórios
- [conteudo-publico.md](.claude/rules/conteudo-publico.md): o que pode e o que não pode ser publicado (o repositório é público)
- [git-e-pr.md](.claude/rules/git-e-pr.md): branch, commit e Pull Request (a `main` é protegida)

## Skills

- `/novo-projeto-desafio`: cadastra um projeto novo, ou seja, um processo seletivo ou uma vaga com seus desafios
- `/adicionar-desafio`: inclui uma área ou um desafio em um projeto que já existe

Para cadastrar ou alterar desafios, use as skills. Não crie pastas à mão.
